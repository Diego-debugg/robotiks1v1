## 📖 Introducción

**Robotics01** es un repositorio dedicado al desarrollo y estudio de algoritmos de **robótica de manipuladores**, enfocado principalmente en:

- 🔹 **Cinemática directa** (Forward Kinematics)
- 🔹 **Cinemática inversa** (Inverse Kinematics)
- 🔹 **Dinámica de manipuladores** (Robot Dynamics)

Los códigos aquí presentados están construidos principalmente sobre dos herramientas clave del ecosistema de robótica en Python:

- 🧰 **[Robotics Toolbox for Python](https://github.com/petercorke/robotics-toolbox-python)**, desarrollado por Peter Corke, utilizado para el modelado, simulación y análisis cinemático/dinámico de robots manipuladores.
- 🦾 **[RoboDK API](https://robodk.com/doc/en/RoboDK-API.html)**, empleada para la simulación offline, programación y control de robots industriales.

Este repositorio busca servir como base de referencia y experimentación para quienes deseen comprender e implementar los fundamentos matemáticos y computacionales detrás del movimiento y control de robots.
